# Agent guidance

This repository is a personal GitHub Pages site built from plain HTML, CSS, and
JavaScript. There is no build step or package manager.

- Keep changes focused on the site or its Pages deployment.
- Preserve the existing no-tracking, no-build approach; do not add dependencies
  unless a concrete requirement needs them.
- Keep personal content and links unchanged unless the task specifically asks
  for those edits.
- When changing the page, verify the HTML structure and any affected links.
- When changing Actions workflows, use the narrowest permissions and validate
  the workflow configuration.
